# Portfólio · José Henrique Jung Heinen

Assistente de TI com atuação em desenvolvimento. Desenvolvo sistemas web internos em PHP, MySQL e Oracle, cuido do suporte, do Microsoft 365 e da documentação de sistemas.

**Acesse o portfólio:** https://josejungheinen.github.io/Portifolio/

## O que tem no portfólio

**Sistemas web**
- Sistema de Compras e Almoxarifado: requisição, cotação, aprovação por alçada, ordem de compra e estoque por filial
- Inventário de peças integrado ao ERP (Oracle)
- Portal único de acesso com permissões por sistema e por tela
- Sistema de notas fiscais, requisições com SLA, portal de veículos, controle de OFP, gestão de projetos e multas da locadora

**Outros projetos**
- Borderô de Pagamento: PRD e protótipo funcional
- Etiquetas de inventário para impressoras Zebra (EPL2)
- Treinamentos dos sistemas internos
- Digitalização de manual técnico com OCR
- Microsoft 365, Windows e planilhas

## Sobre o código

Os sistemas foram desenvolvidos para a empresa onde trabalho, então o código-fonte não é público. O portfólio descreve o problema, a solução e o resultado de cada um, com ilustrações e dados de exemplo.
